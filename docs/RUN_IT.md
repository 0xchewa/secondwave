# Запуск и управление

## Первый запуск

Нужны Node.js 22.x (не ниже 22.12), npm и Git. На Windows рекомендуем Windows Terminal. Минимум 64×24 символа; от 120 столбцов список и карточка видны одновременно.

```sh
git clone https://github.com/0xchewa/secondwave.git
cd secondwave
npm ci
npm start
```

Вместо Git можно скачать Code → Download ZIP и открыть терминал в распакованной папке. `npm ci` устанавливает зависимости. Повторный запуск — только `npm start`.

Первый экран использует включённую запись реальных on-chain наблюдений. Метка RECORDED и время относятся к записи. Все оценки вычисляются локально; сеть при таком запуске не используется.

## Клавиши

| Клавиши | Действие |
| --- | --- |
| 1 / 2 / 3 | Early Signal / Second Wave / сведения о моделях |
| ↑ / ↓, j / k, PgUp / PgDn | Навигация по всему локальному списку |
| / | Поиск по символу, названию или CA |
| s / f | Сортировка / фильтр |
| Enter / Esc | Карточка / назад |
| e | Экспорт выбранного токена и его расчётов в `.local` |
| l | Начать самостоятельный сбор через RPC |
| ? | Подсказки |
| q / Ctrl+C | Выход с сохранением уже завершённых страниц |

Цена `0.0{7}1234` означает семь нулей после десятичной точки до значащих цифр. Точное десятичное значение находится в JSON. ETH обозначает quote unit, а не доллары. График показывает сохранённые сделки, не полный lifetime OHLCV.

## Собственный RPC

Скопируйте `.env.example` в `.env`. Укажите `SWAVE_RPC_URL`. Без настройки используется официальный публичный endpoint. URL с ключом провайдера не добавляйте в Git.

```dotenv
SWAVE_RPC_URL=https://rpc.mainnet.chain.robinhood.com
```

```sh
npm start -- --live
```

Нужна Robinhood Chain **mainnet 4663**. Консоль проверяет chain ID. Провайдер должен поддерживать чтение исторических logs, transactions, receipts и block headers; исторический `eth_call` нужен для деклараций миграции и reserve progress. HTTP разрешён только для localhost, внешние адреса — HTTPS. Отправка транзакций и подписи отсутствуют.

Сбор продолжается с блока seed, а затем с собственного checkpoint. При отставании видна метка CATCHING UP; сохранённая дата не заменяется временем компьютера. Чем старше seed, тем дольше первый проход. Публичный RPC имеет ограничения; свой провайдер с подходящими лимитами ускоряет сбор. Коллектор читает не более десяти заголовков в одном batch и оставляет 20 блоков подтверждений.

Конечный проход и просмотр его результата:

```sh
npm start -- sync --pages 2 --blocks 1000
npm start -- snapshot --state .local/checkpoint.json.gz --mode wave
npm start -- inspect 0xYOUR_CONTRACT --state .local/checkpoint.json.gz
```

`--pages`: 1–100, `--blocks`: 1–2000. CA должен присутствовать в локальной сессии. Поиск не загружает произвольный старый токен из внешнего API.

## Перенос записи

```sh
npm start -- export --state .local/checkpoint.json.gz --output .local/session.json.gz
npm start -- --input .local/session.json.gz
npm start -- snapshot --mode early --json
```

`--input` — переносимые входы для воспроизведения. Полный checkpoint для продолжения RPC также содержит накопленные causal counters; перенос одного session-файла их не заменяет. Не сочетайте `--input` и `--live`.

## Ошибки и восстановление

- **401/403:** проверить ключ и разрешения RPC; завершённый checkpoint остаётся.
- **429 / timeout:** повторить позже или использовать другой RPC. Повторы ограничены; незавершённая страница не продвигает курсор.
- **REORG / ARCHIVE UNAVAILABLE:** проверить исторический доступ и block hash через доверенного провайдера. Для реального reorg нужен checkpoint до расхождения или новый проверенный seed. Автоматического перескока поверх расхождения нет.
- **LOCAL_STATE_LOCKED:** проверьте PID в соседнем `.lock`. Если процесс действительно завершился аварийно, удалите только этот lock-файл и запустите снова. Не удаляйте блокировку работающего сборщика.
- **Недостаточная история:** это состояние покрытия, а не низкая оценка токена. Прочитайте причину в карточке и [границы сборщика](DATA_SOURCES.md).

Проверки: `npm run check`, `npm run build`, `npm test`, `npm run bench`. Для запуска скомпилированной версии после сборки: `node dist/cli.js`.
